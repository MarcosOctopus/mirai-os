# MIRAI OS — System Map / Arquitetura do Ecossistema

## 1. MIRAI OS (app.miraitohope.com)

**Tecnologia**: Next.js 15.5.19, Node.js, TypeScript
**Servidor**: Porta 3333, roteado via Caddy (HTTPS) + Cloudflare (DNS/proxy)
**Deploy**: `cd /opt/data/mirai-app && npx next start -p 3333`
**Watchdog**: Cron a cada 5min (job: eae83647bdde)

### Rotas
| Rota | Descricao | Stack |
|------|-----------|-------|
| /api/chat | Chat streaming | claude-opus-4-8 via MyAPI |
| /api/tts | Text-to-Speech | ElevenLabs, chunk 500 chars, concat MP3 |
| /api/stt | Speech-to-Text proxy | Whisper small (porta 8765) |
| /api/arca | Proxy Arca | arca.miraitohope.com |
| /api/config | Config do cliente | modelo, voz |
| /system | Control Center | Painel de controle visual |

## 2. ARCA (Memoria Persistente)

**URL**: arca.miraitohope.com (API v2.1.0)
**Banco**: PostgreSQL (arca@127.0.0.1:5433)
**Codigo**: /opt/data/arca/
**Fallback SQLite**: /opt/data/arca/api/mirai_memory.db

### Endpoints
- GET /health
- GET /context?q= (busca documentos + memorias + decisoes)
- GET /memory/search?q=
- GET /project/{name}
- GET /timeline/{project}
- GET /executive-brief
- POST /memory (apenas interno - 403 publico)

### Tabelas
documents(75), memories(38), people, companies, projects, decisions(5),
meetings(12), tasks(4), risks(0), opportunities(1), relationships(16), activities(28)
